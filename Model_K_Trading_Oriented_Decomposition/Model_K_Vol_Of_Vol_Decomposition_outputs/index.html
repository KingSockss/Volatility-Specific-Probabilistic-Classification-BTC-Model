Model K Lagged Vol-of-Vol Decomposition

This directory contains five segment-specific copies of the usual Model K outputs, split by minute-level BTC vol-of-vol measured from Binance 1-minute candles and classified with a lagged trailing 72-hour real-time window.

Real-Time Vol-of-Vol Definition

Minute volatility is abs(log(close/open)) for each Binance 1-minute candle. For forecast minute t, vol-of-vol is the standard deviation of minute volatility over the prior 4320 minutes ending at t-1, then assigned to t. Classification uses the rolling percentile cutoffs of that lagged vol-of-vol series, so no target-minute Binance return is used.

Shared Root Files

  • binance_1m_klines.csv: cached Binance minute data used for the decomposition.
  • binance_minute_vol_of_vol.csv: minute volatility, lagged vol-of-vol, and rolling real-time thresholds.
  • minute_market_vol_of_vol_segments.csv: each scored Kalshi forecast minute with lagged vol-of-vol, rolling thresholds, and segment flags.
  • segment_thresholds.csv: summary statistics for the rolling percentile cutoffs used in this run.
  • all_scored_rows_with_vol_of_vol.csv: scored Model K rows with attached minute-level vol-of-vol metadata.
  • excluded_*_insufficient_vol_of_vol_history.csv: rows dropped only when --drop-insufficient-history is used with a partial local cache.
  • kalshi_official_outcomes_long.csv: official contract outcomes used for all segment runs.
